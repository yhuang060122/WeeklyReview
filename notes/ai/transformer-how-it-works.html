A

The Big Picture

A Transformer takes a sequence of tokens as input. It returns a sequence of tokens as output. Since tokens come from text, we can call it a text-in, text-out machine.

Why older models failed

Recurrent models read one word at a time. They forgot early words in long sentences. They also ran slowly, because each word waited for the one before it.

The Transformer processes all tokens at once. Every token looks directly at every other token. Long-range links stop being a problem. Parallel training became much faster.

B

From Words to Numbers

The model only understands numbers. The first step converts words into numbers.

  1. Tokenization splits text into small pieces. Each word becomes one token.
  2. Embedding maps each token to a vector. Similar words get similar vectors.
  3. Positional encoding adds word order. "I love AI" must differ from "AI love I".

Positional encoding is like a seat number. All tokens arrive at once, but each one knows its place.

C

Attention: The Heart

Attention is the single idea that makes everything work. Each word becomes three vectors.

  1. Query: what this word looks for
  2. Key: what this word can offer
  3. Value: the information this word carries

Each Query compares with every Key. The scores become probabilities that add up to 1. The word then collects a weighted mix of Values. "it" ends up carrying a strong signal from "cat".

D

Multi-Head Attention

The model runs attention many times in parallel. Each head studies a different relationship. One head finds subject-verb links. Another head links adjectives to nouns. All outputs combine into one rich representation.

E

One Block, Then Many

One block holds two sub-layers. The attention sub-layer finds relationships. The feed-forward sub-layer refines each word alone.

Every sub-layer keeps a residual connection and a layer norm. The residual adds the sub-layer input back to its output. Layer norm keeps the numbers in a stable range.

The model stacks many blocks. Each block feeds the next one. The original model uses 6 blocks per half. GPT-3 (175B) uses 96 blocks.

Multi-head attention is not the same as stacking. Multi-head runs heads in parallel inside one block. Stacking places full blocks one after another.

F

Encoder vs Decoder

Encoderreads the input
  • Self-attentionevery token sees every token
  • Feed-forwardrefines each token
  • Residual + Layer Normafter each sub-layer
Decodergenerates the output
  • Masked self-attentionpast tokens only
  • Cross-attentionpulls info from the encoder
  • Feed-forwardrefines each token
  • Residual + Layer Normafter each sub-layer

The encoder reads and understands the input. The decoder writes the output, one token at a time.

The decoder cannot see future words. Future words do not exist yet. We call this restriction causal masking.

Cross-attention is the bridge. The Query comes from the decoder. The Key and Value come from the encoder's output.

G

Full Flow: Translation Example

Encoder phase, for "I love learning":

  1. Tokenize into "I", "love", "learning"
  2. Embed each token
  3. Add positional encoding
  4. Pass through 6 encoder layers

Decoder phase, one token at a time:

  1. Start token, cross-attention, pick "J'"
  2. Look back at "J'", pick "adore"
  3. Look back at both, pick "apprendre"
  4. Emit the "end" token

Final output: "J'adore apprendre". The decoder picks each word from probabilities over the whole vocabulary.

Three Variants

Variant Example Best for
Encoder-only BERT classify, understand text
Decoder-only GPT generate text, chat
Encoder-Decoder T5 translate, summarize
Why it won

Parallel training. Direct long-range links. Scales with layers, heads, and data. One architecture powers almost every modern LLM.
