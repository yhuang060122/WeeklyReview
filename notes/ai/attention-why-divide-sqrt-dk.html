为什么注意力要除以 √dₖ

点积方差 = dₖ，除以 √dₖ 后回到 1，softmax 不再饱和

sourceOutcome School · Amit Shekhar

导语：注意力分数 Q×Kᵀ 的方差等于 dₖ。维度越大，分数越分散。除以 √dₖ 把方差拉回 1，softmax 的输入保持健康，梯度不消失。这个数不是随便选的，是算出来的。

公式里的 / √dₖ 就是缩放因子。分数进入 softmax 之前，先除以键维度的平方根。

B

不缩放的后果

真实模型的 dₖ 是 64、128 甚至更大。分数变大后，softmax 只认一个词，模型学不到其他位置的词。

C

点积为什么随 dₖ 增长

点积 = q₁k₁ + q₂k₂ + … + q_dₖ·k_dₖ，共 dₖ 项。 假设每个元素独立，均值 0、方差 1：

  • 单个乘积 qᵢkᵢ 的方差 = 1
  • 相加 dₖ 项，方差 = dₖ

dₖ 越大，分数越分散。这就是问题的根源。

D

方差等于 dₖ：逐步证明

以 dₖ = 3 为例，展开 (q₁k₁ + q₂k₂ + q₃k₃)²，共 9 项：

分组 示例 数量 每项均值
自乘项 (qᵢkᵢ)² = qᵢ²kᵢ² 3 1 × 1 = 1
交叉项 (q₁k₁)(q₂k₂) = q₁k₁q₂k₂ 6 0 × 0 × 0 × 0 = 0

方差 = 3 × 1 + 6 × 0 = 3 = dₖ。 推广到任意 dₖ：dₖ 个自乘项各贡献 1，其余 dₖ² − dₖ 个交叉项各贡献 0。这是精确等式，不是近似。

F

为什么恰好是 √dₖ

直觉：方差用平方差计算，所以除以 c 后，方差变成除以 c²。要让 dₖ / c² = 1，c 只能是 √dₖ。

真实数字对比

小维度 dₖ = 4：q = [1,0,1,0]，k = [0,1,1,1]，点积 = 1，缩放后 = 0.5。数值本来就不大，缩放影响很小。

大维度 dₖ = 64，三个词的分数 [14, 10, 12]：

处理 softmax 输入 输出 结果
不缩放 [14, 10, 12] [0.867, 0.016, 0.117] 86.7% 压在一个词
除以 √64 = 8 [1.75, 1.25, 1.5] [0.419, 0.254, 0.326] 注意力分布均匀

缩放后，三个词都能被学习到。

核心总结

一句话带走
  • 问题：点积方差 = dₖ，大分数让 softmax 输出贴近 0/1，梯度消失
  • 解法：除以 √dₖ，方差回到 1
  • 依据：Var(x/c) = Var(x)/c²，解 dₖ/c² = 1 得 c = √dₖ
